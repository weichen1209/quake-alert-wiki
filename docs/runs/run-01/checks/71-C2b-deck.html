W R4 第3、4頁 說明 第3頁的「近震央」和第4頁規模卡的「震源釋放的總能量」，到第5頁才解釋震源、震央；可把第5頁移到第4頁前，或在第3、4頁備註提示「後面會講」
W R4 第9、10頁 說明 第9頁寫「來源沒有給盲區的範圍，所以這裡不給距離」，下一頁的紅圈卻標「試算盲區 約80公里」；第10頁已說明這是算式結果、不是官方範圍，但第9頁可改成「下一頁的試算會算一個簡化的範圍，不是來源給的」，兩頁才接得起來
W R4 第10頁 說明 頁面文字寫「結果是負數，代表這個算式算出S波比警報先到」，但元件畫面不顯示負數，顯示的是「在盲區：S波比警報早到約X秒」，文字和元件的說法對不上，建議改成和元件相同的字句
W R4 第13頁 說明 地震百問卡寫「預估規模5.0、震度4級；或6.5、3級」，省略「以上」和第二組的「規模、震度」字樣，新手不容易讀懂，可寫成「預估規模5.0以上、預估震度4級以上；或預估規模6.5以上、預估震度3級以上」（Wiki：S03的條件是「以上」）
