規模和震度不一樣

規模

震源釋放的總能量。一次地震只有一個值，寫「規模6.5」，不加級。

震度

各地搖晃的激烈程度。各地不同，寫「震度4級」，要加級。

規模像地震本身的大小，震度像你所在位置感受到的搖晃。
出處規模震度

震源在地下，震央在地面

震源

地震錯動發生的起始點，位於地下深處。

震央

震源在地表的垂直投影點。

離震央愈近的地區，通常搖得愈強。

後面試算要用到「離震央多遠」，所以先把震央講清楚。
出處震源與震央

P波先到，S波後到

P波

所有地震波中速度最快，最先抵達測站。

S波

速度次之，破壞力通常大於P波。

中央氣象署的來源沒有給速度數字；速度只有美國USGS有，在試算頁用。P波先到、S波後到如何用於預警，Wiki沒有直接說明（推論：先到的訊號可以提早偵測）。

強震即時警報怎麼運作

目的：讓距離震央較遠的地區，在破壞性震波抵達前提早應變。

  1. 靠近震央的少數地震站，最早收錄到早期震波訊號（原文沒有說是哪一種波）
  2. 快速演算出震央資訊
  3. 推估各地的預估震度，和破壞性S波到達的時間
  4. 快速對外通報
原文寫的是「早期震波訊號」，沒有寫是P波，所以不要在這裡說成P波。

警報不是瞬間發出

  • 島內或近岸發生中大規模地震：約15至20秒演算出初步震央資訊，再用1至2秒對外通報。
  • 2016年2月6日美濃地震：約12秒即演算出初步震央資訊，對台北地區可提供49秒的預警時效。

兩條的條件不同，不能互相替換。

為什麼有時候先搖才響

  • 資料處理需要一定的時間。
  • 近震央地區接收到警報時，S波可能已經到達，這些地區稱為預警盲區。
  • 越靠近震央，預警時間越短；通報比S波更快到達時，可爭取數秒至數十秒。

來源沒有給盲區的範圍，所以這裡不給距離。

試算：離震央多遠還來得及

距離是你和震央的距離。結果是負數，代表這個算式算出S波比警報先到。紅圈是算式的結果；來源沒有給盲區範圍，這不是官方範圍。

S波速度用美國USGS的每秒2.5英里（換算：約4.0公里/秒）；警報秒數用中央氣象署通報軟體約20秒內，簡化成20秒。兩個數字來自不同國家，是簡化估算。

發布警報秒數用20是學生的決定：通報軟體約在地震發生後20秒內完成通報與告警，PWS約在20多秒內。S波速度只有美國USGS的數字，中央氣象署沒有給。算式（距離除以S波速度，再減警報秒數）是簡化算法，Wiki沒有寫（推論：根據是預警時間要比較S波到達和警報發出的時間）。

三個常見誤解

規模6.5級？

誤植。正確寫法是「規模6.5」。

規模大就一定災情大？

還要看震源深度和震央距離：震源淺、離震央近，通常搖得更強。

警報會預測地震？

不會。地震發生後才通報。

警報的其他限制：連續地震時可能無法精確分辨波形；雜訊可能被誤判為地震而誤報。

四個名稱的差別

名稱做什麼
地震預報預測地震，目前無法準確做到
地震速報地震發生後彙整有感地震報告
強震即時警報搶在破壞性震波抵達前通報
國家級警報讓手機收到文字與聲響告警（PWS，是強震即時警報的通報管道之一）

這是〈地震百問〉的分法；不同來源對「地震速報」的用法不同。

不同來源對「地震速報」和手機訊息的關係說法不同，這裡只用地震百問的分法。

  1. 1989年成立地震測報中心
  2. 2016年國家通訊傳播委員會開始推動災防告警廣播訊息系統（PWS）
  3. 113年6月5日專家學者會議討論新增條件

收到警報怎麼做

PWS會在強震發生後的短短數秒至數十秒內發送預警訊息，要立刻行動。

室內

迅速掩護，遠離窗戶和吊燈等易碎落物。

室外

尋找開闊地蹲下，保護頭部。

駕駛中

減速靠邊停車，地震結束後再行駛。

這是新聞稿的三句話，不是完整防護說明。

完整的防護步驟，Wiki還沒有來源；「掩護」要做什麼動作，Wiki沒有更多說明。
