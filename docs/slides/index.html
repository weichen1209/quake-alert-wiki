出處預警時間與盲區

震源在地下，震央在地面

震源

地震錯動發生的起始點，位於地下深處。

震央

震源在地表的垂直投影點。

離震央愈近的地區，通常搖得愈強。

後面的規模和試算都會用到震源和離震央多遠，所以先講這一頁。
出處震源與震央

規模和震度不一樣

規模

震源釋放的總能量。一次地震只有一個值，寫「規模6.5」，不加級。

震度

各地搖晃的激烈程度。各地不同，寫「震度4級」，要加級。

規模像地震本身的大小，震度像你所在位置感受到的搖晃。
出處規模震度

P波先到，S波後到

P波

所有地震波中速度最快，最先抵達測站。

S波

速度次之，破壞力通常大於P波。

中央氣象署的來源沒有給速度數字；速度只有美國USGS有，在試算頁用。P波資料怎麼用於預警，見下一頁（說明頁：用前幾秒P波資料演算）。
出處P波與S波

強震即時警報怎麼運作

目的：在破壞性的S波抵達前，讓離震央較遠的地區提早應變。

  1. 靠近震央的少數地震站，最早收到前幾秒的P波資料（說明頁的說法）
  2. 快速演算出震央資訊：發震時間、位置、深度、規模
  3. 推估各地的預估震度和S波到達時間
  4. 快速對外通報

用途例子：高速行進間的交通運輸系統自動減速甚至停止；電梯停在安全位置並疏散乘客。

P波資料是說明頁的說法；地震百問寫「早期震波訊號」、原理頁寫「早期震波資料」，沒說是哪種波，兩種寫法並列。原文寫的是交通運輸系統，不是列車。
出處強震即時警報

警報不是瞬間發出

  • 島內或近岸發生中大規模地震：約15至20秒演算出初步震央資訊，再用1至2秒對外通報。
  • 2016年2月6日美濃地震：約12秒即演算出初步震央資訊，對台北地區可提供49秒的預警時間。

第一條是一般說法，第二條是一次實際例子。

原文沒有說明12秒是否包含通報時間。
出處強震即時警報預警時間與盲區

為什麼有時候先搖才響

  • 資料處理需要時間。
  • 近震央地區收到警報時，S波可能已到達，稱為預警盲區；警報比S波早到的時間叫預警時間，越靠近震央越短。
  • 說明頁（頁面標示110年9月2日）：盲區內的人收到預警時，已經或正在感受S波；盲區外有數秒至十數秒的應變時間。

來源沒給盲區距離；下一頁試算會算一個簡化範圍，不是來源給的。

這是學生最想弄懂的問題，多花一點時間。說明頁只說盲區範圍取決於測震密度與即時訊號品質。說明頁的數秒至十數秒沒有距離條件；上一頁美濃地震台北49秒是地震百問的單一例子，條件不同，不能互相比較。

試算：離震央多遠還來得及

紅圈是算式的結果，不是官方範圍。

S波速度用美國USGS的每秒2.5英里（換算：約4.0公里/秒；USGS把S波和表面波合在一起給）；警報秒數用地震百問寫的手機收到警報時間，約在地震發生後20多秒內，簡化成20秒。兩個數字來自不同國家，是簡化估算。

發布警報秒數用20是學生的決定：手機（PWS）約在地震發生後20多秒內收到警報，簡化成20秒，比原文少算了幾秒；通報軟體約20秒內完成通報與告警，只當對照。S波速度只有美國USGS的數字，中央氣象署沒有給。算式（距離除以S波速度，再減警報秒數）是簡化算法，Wiki沒有寫（推論：根據是預警時間要比較S波到達和警報發出的時間）。

警報有哪些限制

  • 預警盲區：近震央來不及。
  • 測報時效：海域或測站少的地方，要等收到足夠訊號才能演算。
  • 誤報或漏報：全由系統自動演算，沒有人工確認。
  • 資訊誤差：只用少量訊號快速演算，和用全部地震站訊號算出的地震報告有誤差。

以上是說明頁的四項。另外，連續地震時可能分不清波形，日本就曾發生數次誤報；雜訊也可能被誤判為地震。

連續地震和雜訊誤報來自原理頁；日本的誤報寫在連續地震那一項，原文沒有寫年份和次數。

三個常見誤解

規模6.5級？

誤植。正確寫法是「規模6.5」。

規模大就一定災情大？

還要看震源深度和震央距離：震源淺、離震央近，通常搖得更強。

警報會預測地震？

不會。地震發生後才通報。

警報本身的限制，見上一頁。

四個名稱的差別

名稱做什麼
地震預報預測地震，目前無法準確做到
地震速報地震發生後彙整有感地震報告
強震即時警報搶在破壞性震波抵達前通報
國家級警報強震即時警報傳到手機的方式之一（地震百問）：經災防告警廣播訊息系統（簡稱PWS）發送

同樣叫「地震速報」，指的東西不同：地震百問指地震後彙整的有感地震報告；新聞稿、說明頁指PWS發到手機的地震速報，屬於強震即時警報服務。

細胞廣播技術讓政府能短時間內大量傳送示警訊息到手機。說明頁（頁面標示110年9月2日）說收到地震速報時手機會強制發出警報音效。國家級警報故事文則說速報系統是手機地震訊息最原始的樣子。三種說法並列，沒有來源說哪一種是現行。

國家級警報的時間線

  1. 1989年成立地震測報中心
  2. 2016年國家通訊傳播委員會開始推動PWS
  3. 105年（2016年）5月12日地震速報和地震報告透過PWS上線（說明頁）
  4. 107年（2018年）5月15日停止PWS的地震報告產品服務（說明頁）
  5. 110年（2021年）9月2日說明頁標示的日期，已列出規模6.5條件
  6. 113年（2024年）6月5日、7月17日兩次會議討論通過新增條件（新聞稿）
  7. 113年（2024年）9月1日新增規模6.5條件上線（新聞稿）

規模6.5條件：說明頁已經列出，新聞稿說是新增；實際從哪一年開始，來源沒有說明。

兩次會議是專家學者會議和防救災單位會議。說明頁沒有說明PWS的地震報告產品內容。不能確定新聞稿的日期就是條件的起點。1989年、2016年是西元年，其餘是民國年，括號裡是西元年。

收到警報後、地震搖晃時怎麼做

收到警報後（新聞稿，113年8月30日）

室內：迅速掩護，遠離窗戶和吊燈等易碎落物。室外：找開闊地蹲下，保護頭部。駕駛中：減速靠邊停車，地震結束再行駛。

地震搖晃時（保命三步驟文章，日期未標示）

趴下、掩護、穩住：趴下並護住頭頸，躲到穩固的桌子底下。因為通常是物品掉落、移位或翻覆砸傷人。

兩種是不同的情境。室外兩篇說法不同：新聞稿找開闊地，三步驟文章找可掩護的地方並留意落物；兩篇都沒有說哪一個適用什麼場合。

行動不便者（輪椅、病床等）改用固定、掩護、穩住，鎖住車輪、保持坐姿、護住頭頸。握住桌腳，是因為桌子隨地震移動時，桌下的人可以跟著移動。三步驟文章說強烈晃動前可能只有幾秒，沒有提警報，也沒有說適用的震度。新聞稿的三句不是完整防護說明。

新聞稿說訂於113年9月1日上線的新增條件是哪一個？

新聞稿說新增的是預估規模達6.5且預估震度達3級；規模5.0且震度4級是現有條件。說明頁和地震百問也寫了同一組條件，但沒說是新增；來源沒有說明哪一篇對。

出處國家級警報

記住這六件事

  1. 規模只有一個值，震度各地不同
  2. P波先到；S波後到，破壞力通常較大
  3. 強震即時警報用最早收到的震波資料演算，搶在破壞性震波前通報
  4. 資料處理需要時間，近震央有預警盲區，所以有時先搖才響
  5. 國家級警報：預估規模5.0以上、預估震度4級以上的縣市；或預估規模6.5以上、預估震度3級以上（新聞稿、說明頁、地震百問這樣寫，另外兩篇不同）
  6. 收到警報後（新聞稿）：室內掩護、室外找開闊地蹲下、駕駛中靠邊停車；地震搖晃時（保命三步驟文章）：趴下、掩護、穩住
回到開頭的問題：先搖才響，是因為資料處理需要時間，近震央的盲區來不及收到警報。第6點是兩種不同的情境。
