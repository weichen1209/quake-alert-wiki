討論單 D01：S01 國家級警報來了--地震測報過程

AI：這篇的重點

這篇是交通部中央氣象署數位科普網的文章，用小P和爸爸的對話說明國家級警報和地震測報過程；原文發布日期未標示S01。

  1. 國家級警報的發布條件：「當中央氣象署偵測到臺灣及其周圍海域發生規模5以上的地震，且預估至少一縣市政府所在地震度達5級以上，即會針對震度4級以上地區擁有4G手機的民眾發送地震警報訊息」S01。
  2. 系統的起點：「國家通訊傳播委員會（NCC）自2016年起開始推動『災防告警廣播訊息系統（Public Warning System，PWS）』」S01。
  3. 手機收到的是4G系統送出的訊息：「經由此系統可將重大天然災害的最新訊息傳送給擁有4G功能的手機使用者知悉」S01。
  4. 氣象署的測報單位：「於1989年就已成立『地震測報中心』」S01。
  5. 地震速報系統的功能：「在地震發生後的數十秒至數分鐘內立即對外發出地震資訊，其內容包含：震央位置、規模、震度分布圖及重要設施搖晃情形」S01。
  6. 地震發布流程分四步：「（1）氣象署所屬的地震觀測站偵測到有感地震之後、（2）立即啟動強震即時警報系統、（3）同時可得出地震定位報告（包括：發生時間、震央位置、地震深度、地震規模、各地震度）、（4）然後經由速報系統將地震資訊對外發布」S01。
  7. 地震消息的四種發布途徑：「（1）於中央氣象署網站公布、（2）透過手機簡訊和傳真方式傳給各相關防救災單位與大眾傳播媒體、（3）發送電子郵件給國內外學者專家、（4）於166、167氣象語音專線上報導」S01。
  8. 文章用一個山上的情境給行動建議：「只要遠離邊坡、注意落石，並立即找個空曠的地方就地避難就好」S01。
  9. 文章說明臺灣地震多的原因：「臺灣位於歐亞大陸板塊與菲律賓海板塊交界處」S01。

AI：和現有Wiki的關係

目前Wiki只有D00規劃，沒有概念頁、主題頁或其他來源頁，所以這篇的內容都還不能和別的來源比對。

  • 新增：sources/S01-cwa-edu-pws-story.md，放上面的重點和出處S01。
  • 新增：topics/國家級警報.md 的初版，放發布條件、起點、4G手機、發布流程和發布途徑，條件寫成這篇的說法、日期未標示S01。
  • 新增：topics/警報名稱比較.md 先放這篇對地震速報系統、強震即時警報系統、國家級警報的說法，之後再補其他來源S01。
  • 修改：wiki/index.md、wiki/overview.md（只寫目前能寫的部分）、wiki/log.md。
  • 不新增：concepts/強震即時警報.md。這篇只在流程第（2）步提到「強震即時警報系統」，沒有定義、速度或秒數，不足以建頁，也提供不了預警時間試算要用的數字S01。
  • 和其他來源不一致：還不能比對，但這篇有幾處可能過時或沒寫日期，之後取得其他來源時要查：
    • 發布條件（規模5以上、預估至少一縣市政府所在地震度達5級以上、震度4級以上地區）沒寫是哪一天的規定，原文也沒標示發布日期；D00提到後面有更新的新聞稿，可能已經改過S01。
    • 「擁有4G手機的民眾」只寫4G，沒說其他手機是否收得到S01。
    • 系統名稱前後不同：先寫「災防告警廣播訊息系統」，後面又寫「災防告警廣播訊息服務系統」，兩者是否同一個要確認S01。
    • 文章同時寫「中央氣象署」和簡稱「CWB」，單位名稱可能是舊稱的遺留，Wiki寫法要統一S01。
    • 爸爸說地震速報系統「也就是我們手機顯現的地震訊息最原始的樣子」S01，把地震速報和手機警報說成同一條線；這和D00要釐清的三個名稱關係可能不同，要用其他來源核對S01。
    • 原文有錯字（例如「人囗」），引文時要避開，Wiki頁不照抄錯字，raw不改S01。

AI：想問的問題

  1. 發布條件沒有日期，只有這一篇來源。topics/國家級警報.md 要現在就建，條件標成「S01的說法，日期未標示」，等cwa-press-2024-pws再比對？還是這一篇只放進來源摘要頁，等有日期明確的來源再建主題頁？
  2. 這篇把「地震速報系統」說成手機訊息最原始的樣子，和強震即時警報的關係也只是流程的一個步驟。警報名稱比較.md 要不要先照原文列出這篇的說法並標明出處，等後面幾篇再整理？還是先不建這頁？
  3. 山上避難的建議只是故事裡的情境，不是正式指引，也不是完整的「收到警報怎麼做」。要放進來源摘要頁當一個例子（標明是這篇的情境），還是先不寫，等取得防護類來源後再處理？
  4. 系統名稱兩種寫法、單位簡稱CWB這些前後不一致的地方，Wiki頁要怎麼寫：照原文各自標出處並列，還是統一成一種寫法再加註說明？

學生回覆

  1. 現在就建。條件寫明是S01的說法、沒有日期，等113年的新聞稿進來再比對。
  2. 先不建。這篇只把強震即時警報當成流程的一步，等地震百問講到速報和預警差別的那篇進來再建。
  3. 只放在來源摘要頁，寫明是故事裡的情境，不當成正式的避難建議。
  4. 引文照原文。Wiki自己寫的句子單位統一寫中央氣象署；系統名稱等有官方說明的來源進來再統一，現在先註明這篇有兩種寫法。

決定

  • 新增 sources/S01-cwa-edu-pws-story.md：放重點，山上避難的建議只放在這頁，寫明是故事裡的情境，不當成正式的避難建議；系統名稱的兩種寫法在這頁註明S01。
  • 新增 topics/國家級警報.md：現在就建，發布條件寫明是這篇的說法、原文沒有日期，等日期明確的新聞稿進來再比對S01。
  • 不新增 topics/警報名稱比較.md：這篇只把強震即時警報當成流程的一步，等地震百問中講速報和預警差別的那篇進來再建S01。
  • 不新增 concepts/強震即時警報.md，也不建 topics/收到警報怎麼做.mdS01。
  • 引文照原文；Wiki自己寫的句子，單位統一寫中央氣象署；系統名稱先註明這篇有兩種寫法，等有官方說明的來源再統一S01。
  • 修改 wiki/index.md，加來源和主題兩節；wiki/overview.md 先不建，目前內容不足以串成總覽，等後面幾篇來源進來再建S01。
  • 在 wiki/log.md 加一筆ingest紀錄S01。
