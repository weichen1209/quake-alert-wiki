概念

  • 規模：描述地震大小的絕對尺度，依震源釋放的總能量而定，同一次地震只有一個值，和震度的倍數並列對照
  • 震度：各地搖晃的激烈程度，中央氣象署分0級到7級，頁內有完整分級表
  • 震源與震央：震源是錯動起始點，震央是地表投影點；含震源深度和震央距離對搖晃的影響
  • P波與S波：兩種體波的性質和快慢；速度數字待後續來源補
  • 強震即時警報：利用靠近震央的少數地震站最早收到的震波訊號，搶在破壞性震波前通報；列出各秒數的條件、三種通報管道和應用例子

主題

  • 國家級警報：國家級警報（PWS）的發布條件、發布流程和時間線；S01、S03日期未標示，S05是113年8月30日新聞稿，三篇條件並列，S03和S05對規模6.5條件的說法衝突
  • 警報名稱比較：地震預報、速報、強震即時警報和國家級警報四個名稱的差別；S01、S03、S05對「地震速報」和手機訊息的關係說法不同
  • 預警時間與盲區：為什麼震央附近有時先搖才響；資料處理需要時間、離震央越近預警越短；S波速度和盲區範圍目前來源沒有給
  • 收到警報怎麼做：室內、室外、駕駛中三種情境的防護動作；目前只有S05的三句話
