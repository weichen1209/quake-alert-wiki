概念

  • 規模：描述地震大小的絕對尺度，依震源釋放的總能量而定，同一次地震只有一個值，和震度的倍數並列對照
  • 震度：各地搖晃的激烈程度，中央氣象署分0級到7級，頁內有完整分級表
  • 震源與震央：震源是錯動起始點，震央是地表投影點；含震源深度和震央距離對搖晃的影響
  • P波與S波：兩種體波的性質和快慢；速度數字只有S06（美國USGS，英里/秒）有，頁內有換算和S06自己兩種說法並列
  • 強震即時警報：利用靠近震央的少數地震站最早收到的震波訊號，搶在破壞性震波前通報；列出各秒數的條件、三種通報管道和應用例子；S07明寫用P波資料並列出四項限制
  • 災防告警細胞廣播：災防告警服務（PWS）用細胞廣播技術傳送示警訊息到手機；含地震速報的接收模式、S07對訊息種類的說明和名稱寫法的不同；加S08列的訊息種類和名稱寫法

主題

  • 國家級警報：國家級警報（PWS）的發布條件、發布流程和時間線；S01、S03日期未標示，S05是113年8月30日新聞稿，S07頁面標示110年9月2日，S08原文未寫日期（檔名有20201008），五篇條件並列；S03、S07已有規模6.5條件而S05說是新增，說法衝突；S08只有一段條件，以縣市政府所在地為準，臺北市是3級，並有臺中市和臺北市的說法一節
  • 警報名稱比較：地震預報、速報、強震即時警報和國家級警報四個名稱的差別；S01、S03和S05、S07對「地震速報」和手機訊息的關係說法不同
  • 預警時間與盲區：為什麼震央附近有時先搖才響；資料處理需要時間、離震央越近預警越短；S波速度只有S06有、盲區範圍來源沒有給；含S07的盲區情境說明
  • 收到警報怎麼做：分兩節：S05的收到警報後三種情境，和S09的地震搖晃時趴下、掩護、穩住；室外等動作兩篇說法不同，並列不判斷
