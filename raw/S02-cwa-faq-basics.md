21.主要的地震波有那些?
地震波的種類與傳播方式
當斷層錯動釋放能量時，會產生向四面八方傳遞的波動。地震波依據其「傳播路徑」主要可分為兩大類：
(1)體波Body Wave
可在地球內部深處傳播的地震波，依波動性質之不同又分為以下兩種：
P波
Primary wave縱波/壓縮波
性質與音波相似，其質點運動方向和波傳播的方向一致（平行），是所有地震波中速度最快的波，會最先抵達測站。
S波
Secondary / Shear wave橫波/剪力波
質點運動方向與波傳播方向垂直，會產生前後左右在水平與垂直各方向的振動。其傳遞速度次之，破壞力通常大於P波。
(2)表面波Surface Wave
僅能沿著地球表層或地球內部界面傳播的地震波，主要可分為以下兩種：
洛夫波
Love wave
質點僅沿著水平面產生和波傳播方向垂直的蛇行運動，沒有垂直方向的位移，對建築物地基的水平剪切破壞力極強。
雷利波
Rayleigh wave
質點在平行於波傳播的垂直面上，沿著逆向橢圓形軌跡震動（類似海浪翻滾）。會造成地面上下起伏與前後晃動。

25.何謂規模?
地震規模(Magnitude)
規模（Magnitude）為描述地震大小之絕對尺度，係依據地震發生時震源所釋放之總能量而定。
規模的核心觀念解析
一次地震，單一數值
因規模代表震源釋放之原始能量，故對於同一次地震事件而言，其規模僅具唯一值，不隨觀測測站或地點之不同而改變。
無單位之實數
規模係經由經驗公式計算而得之無單位實數，常以帶有小數點之數值（如6.5或7.2）表示，其本身不具備物理單位。
能量幾何級數放大
當規模數值每增加1.0時，地震波之最大振幅將放大10倍，而其震源所釋放之總能量則呈幾何級數增加約32倍（精確值約31.6倍）。
地震規模與釋放能量比較圖
觀念釐清：規模不加「級」
新聞媒體常有「規模6.5級」之誤植說法，實屬觀念混淆。「規模」代表總能量，不具單位；而「震度」代表各地地表搖晃程度，方需冠以「級」。正確之表述應為「規模6.5，最大震度4級」。

30.地震規模愈大，是否災情愈大?
地震規模與災害的關係
基本上，地震規模愈大其所可能導致的災害應該愈大。但由於地震是一種能量的釋放，以地震波的形式向四方傳播過程中，能量會因岩層的摩擦、吸收而衰減，所以災情大小通常會與震源深度、震央距離相關，但建築物或公共設施的耐震力也直接影響災情嚴重與否。
影響災情大小的關鍵要素
震源深度
震源距離地表之深度直接影響致災程度。淺層地震能量距地表較近，傳播過程之能量損耗較少，致使地表所受之搖晃通常更為強烈。
震央距離
距離震央愈近之地區，接收到之地震波能量愈為集中；反之距離愈遠，地表所感受之強烈振動相對遞減。
岩層摩擦與吸收
地震波向四方傳播時，其能量將因介質傳遞過程中之岩層摩擦與物質吸收效應而逐漸衰減。
建築與設施耐震力
建築物或公共設施之耐震設計、施工規範與結構強度，為直接影響災情嚴重程度之關鍵人為因素。

35.何謂震度?
地震震度(Intensity)與分級
震度（Intensity），是表示地震時地面上的人所感受到振動的激烈程度，或物體因受振動所遭受的破壞程度。現今地震儀器已能詳細描述地震的搖晃情形。

36.地震震度與加速度之關係如何?
震度與加速度之關係
地震震度與加速度的關係，可以心理學家韋伯－費科納法則（Weber-Fechner）來解釋：即刺激的程度（加速度，αI，單位為公分/秒2）成等比數列增加時，感覺的程度（震度，I）將以等差數列增加。
公式計算與物理意義
氣象署採用之震度與加速度關係式
氣象署現所採用的震度階級，其與加速度的關係式如下：
log αI = ( I / 2 ) − 0.6
震度相差1級的物理意義
將震度相差1代入公式推導（100.5 ≈ 3.162），亦即震度相差1級，相當於地動加速度值增減約3倍。
